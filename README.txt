# DP Exposure Trainer — iPhone PWA

## Defaults
- Language: English
- Camera A → Camera B: Simple
- Values: Full stops

## Install on iPhone
1. Upload this whole folder to any HTTPS web host (GitHub Pages works).
2. Open the site in Safari on your iPhone.
3. Tap Share.
4. Tap "Add to Home Screen".
5. Launch DP Exposure Trainer from the new icon.

The app works offline after the first successful load.
